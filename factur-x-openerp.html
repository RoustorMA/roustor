Qu'est-ce qu'une facture Factur-X ?

Factur-X est un format de facture électronique hybride associant deux éléments complémentaires :

  • Un fichier PDF lisible par l'utilisateur.
  • Un fichier XML contenant les données structurées de la facture.

Ce format permet de conserver une facture facilement consultable tout en répondant aux exigences de traitement automatique.

Pourquoi utiliser Factur-X avec OpenERP ?

OpenERP reste utilisé par de nombreuses entreprises pour gérer leur activité commerciale et comptable.

Cependant, les nouvelles obligations de facturation électronique nécessitent la production de documents structurés conformes.

Roustor apporte cette capacité sans remettre en cause l'utilisation de votre environnement OpenERP.

Les standards utilisés

  • Factur-X
    Format hybride combinant PDF et données XML.

  • EN16931
    Modèle européen définissant les règles de la facture électronique.

  • PDF/A-3
    Format permettant l'intégration du fichier XML dans le document PDF.
